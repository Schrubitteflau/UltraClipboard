Salut j'aimerais créer une application native multiplateforme (Windows, macOS, Linux) utilisant Tauri ou une stack équivalente (à la base j'hésitais entre Python Tkinter et Electron, la stack est à débattre), avec interface minimaliste accessible depuis la barre des tâches. L'application doit permettre de gérer des modules de transformation du clipboard, par exemple Uppercase ou transformer une URL YouTube en Markdown [Titre](URL). Chaque module doit pouvoir être sync ou async, et les modules doivent pouvoir être chaînés pour appliquer plusieurs transformations successives sur le texte copié. L’application doit être facile à bundle et installer sur tous les OS. Les fonctionnalités secondaires comme raccourcis clavier, historique des copiés-collés, ou modules additionnels peuvent être envisagées plus tard, mais l’accent doit rester sur le pipeline modulaire du clipboard et l’accessibilité rapide via la barre des tâches.

Pour le framework UI j'aimerais qqc de léger, et je suis curieux d'essayer Svelte, donc peut-être que c'est le bon moment. Ça marche bien avec Tauri?

Oui mais en fait j'aimerais aussi qu'on développe l'idée de l'app, avant tout. Car peut-être que ça a un potentiel dont je n'ai même pas encore idée, qui pourrait influer sur le choix techno d'ailleurs
